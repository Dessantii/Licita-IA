Quero criar uma Landing Page moderna, profissional e focada em conversão para o sistema LicitaIA.

Contexto do produto:
O LicitaIA é uma plataforma web brasileira para gestão de processos de participação pública e captação de recursos.

O sistema possui 4 módulos principais:
1. Licitações
2. Chamamentos Públicos
3. Captação de Recursos
4. Empresas

O objetivo do sistema é reduzir burocracia operacional, automatizar análise documental e facilitar participação em processos públicos.

IMPORTANTE:
A landing page NÃO deve parecer genérica de IA.
Ela deve parecer uma plataforma séria, moderna, confiável e operacional.

Objetivo da landing page:
- Explicar claramente o problema
- Mostrar como o LicitaIA resolve
- Apresentar funcionalidades
- Gerar confiança
- Levar o usuário para login
