# Prompt 04 — Proposta Comercial

## Contexto do sistema

Você está construindo do zero a **etapa de proposta comercial** do LicitaIA — a quarta aba na tela de detalhe do processo (`/processes/:id`).

**O que já existe e deve ser preservado:**
- Aba "Resumo" com dados extraídos do edital (objeto, valor estimado, critério de julgamento, itens/lotes)
- Aba "Análise" com diagnóstico de viabilidade e calculadora básica (construída no Prompt 02)
- Aba "Documentos" com checklist de habilitação (construída no Prompt 03)
- Dados da empresa: CNPJ, razão social, endereço, representante legal, regime tributário
- Itens/lotes do edital já extraídos pela IA em `process_requirements`

**O que este prompt constrói:**
A aba **"Proposta"** — onde o usuário define seus preços, entende se está competitivo e gera o documento final pronto para enviar ao portal.

---

## O problema a resolver

A proposta comercial é o coração da licitação — é o que define se a empresa ganha ou perde. Hoje o usuário:
1. Não sabe qual preço praticar (sem referência de mercado)
2. Não sabe se vai ter margem depois de impostos e custos
3. Precisa criar o documento Word do zero, sem template
4. Frequentemente comete erros de formatação que desclassificam a proposta

A aba "Proposta" resolve os três problemas de uma vez.

---

## O que construir

### Estrutura da aba "Proposta"

A aba é dividida em 3 sub-seções navegáveis por âncora (não tabs):

```
[ 1. Pesquisa de preço ]  [ 2. Monte sua proposta ]  [ 3. Gerar documento ]
```

---

### Sub-seção 1 — Pesquisa de preço de mercado

**Objetivo:** dar ao usuário uma referência de preço antes de definir o seu.

**Fonte de dados:** consultar o PNCP pela API pública buscando contratos/atas com objeto similar nos últimos 24 meses.

**Endpoint PNCP a usar:**
```
GET https://pncp.gov.br/api/pncp/v1/orgaos/{cnpj}/compras?...
GET https://pncp.gov.br/api/consulta/v1/contratacoes/publicacao?...
```

**Parâmetros de busca:** palavras-chave extraídas do objeto do edital + UF do órgão.

### Sub-seção 2 — Monte sua proposta

**Objetivo:** o usuário define o preço de cada item/lote e o sistema calcula tudo em tempo real.

#### 2a. Tabela de itens

Renderizar os itens/lotes extraídos do edital em uma tabela editável:

```
┌──────┬──────────────────────────────┬──────┬──────────┬──────────────┬──────────────┐
│ Item │ Descrição                    │ Qtd  │ Und      │ Preço unit.  │ Total        │
├──────┼──────────────────────────────┼──────┼──────────┼──────────────┼──────────────┤
│  1   │ Seguro auto frota — veíc leve│  32  │ veículo  │ R$ [_____]  │ R$ ______    │
│  2   │ Seguro auto frota — veíc pesado│ 16 │ veículo  │ R$ [_____]  │ R$ ______    │
├──────┴──────────────────────────────┴──────┴──────────┼──────────────┼──────────────┤
│                                              TOTAL    │              │ R$ ______    │
└───────────────────────────────────────────────────────┴──────────────┴──────────────┘
```

- Campos de preço unitário são editáveis
- Total por item e total geral calculados em tempo real
- Ao lado do campo de preço: indicador visual de posicionamento vs. mercado:
  - 🟢 Competitivo (abaixo da média de mercado)
  - 🟡 Na média
  - 🔴 Acima do estimado (risco de desclassificação)

#### 2b. Painel de análise financeira (fixo no lado direito ou abaixo da tabela)

Atualizado em tempo real conforme o usuário digita os preços:

│                                                        │
│  Margem estimada:               —                     │
│                                                        │
│  ─────────────────────────────────────────────────── │
│  🏆 Benefício ME/EPP — Empate ficto                  │

Campo "Custo do serviço" é opcional mas desbloqueado para quem quiser ver a margem real. Não é enviado para nenhum relatório, é só para uso interno do usuário.

**Alerta de desclassificação:** se o total da proposta ficar **acima do valor estimado** pelo órgão, exibir banner vermelho:
```
🚫 Proposta acima do estimado
Seu valor (R$ 345.000) está 4,5% acima da estimativa do órgão (R$ 330.196).
Propostas acima do estimado são geralmente desclassificadas em pregões.
Reduza o preço ou verifique os valores com o edital.
```

#### 2c. Campos complementares da proposta

Campos que completam o documento de proposta além dos preços:

```
Validade da proposta:   [ 60 ] dias  ← mínimo exigido pelo edital: 60 dias
Prazo de entrega:       [___________]  ← conforme edital ou livre se não especificado
Marca / Fabricante:     [___________]  ← obrigatório para alguns editais
Observações:            [___________]  ← campo livre, opcional
```

Pré-preencher "Validade da proposta" com o mínimo exigido pelo edital (extraído na análise).

## Schema de banco de dados

### Nova tabela `process_proposals`
```sql
CREATE TABLE process_proposals (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  process_id UUID NOT NULL REFERENCES processes(id) ON DELETE CASCADE,
  company_id UUID NOT NULL REFERENCES companies(id) ON DELETE CASCADE,

  -- Itens e preços
  items JSONB NOT NULL,
  -- [{ "item_number": 1, "description": "...", "quantity": 32,
  --    "unit": "veículo", "unit_price": 5150.00, "total": 164800.00 }]

  total_value DECIMAL(15,2) NOT NULL,
  validity_days INTEGER NOT NULL DEFAULT 60,
  delivery_term TEXT,
  observations TEXT,

  -- Análise financeira
  estimated_taxes_percent DECIMAL(5,2),
  declared_cost DECIMAL(15,2), -- opcional, uso interno
  calculated_margin DECIMAL(5,2), -- uso interno

  -- Documento gerado
  docx_path TEXT,
  signed_docx_path TEXT,
  generated_at TIMESTAMP DEFAULT NOW(),
  signed_uploaded_at TIMESTAMP,

  -- Status
  status VARCHAR(30) DEFAULT 'draft',
  -- 'draft' | 'generated' | 'signed' | 'submitted'

  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);
```

### Nova tabela `market_price_research`
```sql
CREATE TABLE market_price_research (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  process_id UUID NOT NULL REFERENCES processes(id) ON DELETE CASCADE,
  search_terms TEXT[],
  results JSONB,
  -- [{ "contract_number": "...", "organ": "...", "value": ...,
  --    "date": "...", "unit_price": ..., "quantity": ... }]
  avg_price DECIMAL(15,2),
  min_price DECIMAL(15,2),
  max_price DECIMAL(15,2),
  price_insight TEXT,
  suggested_bid_min DECIMAL(15,2),
  suggested_bid_max DECIMAL(15,2),
  fetched_at TIMESTAMP DEFAULT NOW()
);
```

## Lógica de pesquisa de preço via IA + PNCP

```javascript
// 1. Extrair palavras-chave do objeto
const keywordsPrompt = `
Extraia 2-3 palavras-chave principais do objeto de licitação abaixo para usar em busca de preços.
Retorne apenas um array JSON de strings, sem texto adicional.
Objeto: "${process.object}"
// Exemplo de retorno: ["seguro veículos", "frota", "apólice"]

// 2. Buscar no PNCP
const pncpResults = await fetchPNCPContracts(keywords, uf);

// 3. Analisar resultados com IA
const insightPrompt = `

  "suggested_min": 0,
  "suggested_max": 0

`;
```

## Cálculo de impostos por regime tributário

```javascript
function calculateTaxes(company, proposalValue) {
  const rates = {
    'simples_nacional': {
      'comercio': 0.04,     // Anexo I — até R$ 180k/ano
      'servicos': 0.06,     // Anexo III — até R$ 180k/ano
      'industria': 0.045
    },
    'lucro_presumido': {
      'padrao': 0.1175      // PIS + COFINS + CSLL + IRPJ estimado
    },
    'lucro_real': {
      'padrao': 0.1350
    },
    'mei': {
      'padrao': 0.05        // DAS MEI — valor fixo, aqui % aproximado
    }
  };

  const regime = company.tax_regime;     // campo já existente
  const activity = company.activity_type; // 'comercio' | 'servicos' | 'industria'

  return proposalValue * (rates[regime]?.[activity] ?? rates[regime]?.padrao ?? 0.06);
}
```

## Fluxo completo do usuário

```
1. Usuário chega na aba "Proposta" vindo do checklist de habilitação completo
2. Sub-seção 1: vê referências de preço do PNCP automaticamente carregadas
3. Sub-seção 2: preenche preços na tabela de itens
   → Painel lateral atualiza em tempo real (total, impostos, margem, empate ficto)
   → Alerta aparece se preço ultrapassar estimativa do órgão
4. Preenche validade e prazo de entrega
5. Sub-seção 3: clica "Gerar proposta" → baixa o .docx
6. Assina o documento (fora do sistema)
7. Faz upload da proposta assinada
8. Checklist final aparece → todos os itens ✅
9. Status do processo muda para "Pronto para envio"
10. Usuário acessa portal pelo link e faz o envio
```

---

## Critério de conclusão

Esta etapa está concluída quando:
1. ✅ Sub-seção de pesquisa de preço busca e exibe referências do PNCP
2. ✅ Tabela de itens editável com cálculo em tempo real
3. ✅ Painel financeiro mostra total, impostos, margem e teto do empate ficto
4. ✅ Alerta de desclassificação aparece quando proposta ultrapassa estimativa
5. ✅ Gerador produz arquivo .docx formatado e completo
6. ✅ Checklist final consolida habilitação + proposta + acesso ao portal
7. ✅ Status do processo avança para "Pronto para envio" quando tudo estiver ok
